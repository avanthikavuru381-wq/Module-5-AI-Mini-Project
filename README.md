# AI-Powered Student Performance Predictor

## Module 5 - AI Tools & Mini Project

This project is developed as part of **Module 5 - AI Tools & Mini Project** for the Codomax Digital Solutions internship.

The project demonstrates how Artificial Intelligence, Machine Learning, and AI-assisted development tools can be used to build a simple student performance prediction application.

---

## Project Objective

The main objective of this project is to build a simple AI-powered application that predicts student performance based on input factors such as study hours, attendance, previous score, and sleep hours.

The project also demonstrates how AI tools can support:

- Coding
- Research
- Debugging
- Documentation
- Productivity

---

## Features

- Accepts student performance-related inputs
- Uses a Machine Learning model for prediction
- Displays the predicted performance
- Provides a simple and user-friendly interface
- Demonstrates an AI-assisted development workflow

---

## Input Features

The application uses the following factors:

1. Study Hours
2. Attendance
3. Previous Score
4. Sleep Hours
